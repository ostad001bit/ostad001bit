# 🔗 Supreme GodChain - Modular P2P Blockchain

A doctoral-grade, modular blockchain framework implemented in **Node.js** with support for:

- ⛏️ Mining with difficulty adjustment  
- ⚡ Transaction signing & verification (ECDSA)  
- 🔮 Smart contract deployment and execution  
- 🌐 RESTful API interface per node  
- 📡 P2P WebSocket communication between nodes  
- 🔄 Mempool synchronization  
- 🧪 Designed for multi-node simulation and testing
